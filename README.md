# WINDPROOF

Three.js 製のブラウザー向け 3D ミニゲームです。落ちてくるライターをキャッチし、火をつけて風をよけながら煙草の先に着火するまでの時間を競います。

## 起動方法

Node.js 20.19 以降が必要です。

```bash
npm install
npm run dev
```

表示されたローカル URL をブラウザーで開いてください。

## 操作

- `Space`：落下中のライターをキャッチ
- `B`：キャッチ後に点火
- `Shift`：ライターを持つ手と風よけの手を切り替え
- マウス移動：選択中の手を動かす
- `R`：最初からやり直す

炎がついたら、ライターの手で炎を煙草の先へ近づけ、風よけの手を炎の右側（風上側）に合わせてください。両方の条件を保つと着火します。
