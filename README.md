## 1. アプリ概要・コンセプト

* **どんなアプリか（一言で）**：  
  一人称視点でライターに点火し、風から火を守りながら煙草へ火を移す3Dミニゲームです。
* **ターゲットユーザー・利用シーン**：  
  3Dの手や道具を操作するゲームを短時間楽しみたい人向けです。ブラウザーで操作タイミングに挑戦できます。
* **一番のこだわり・アピールポイント**：  
  ライターを拾う画面と煙草へ着火する画面を分け、右手でスイッチを押してから火をつける流れを実装しました。点火時には炎が大きくなる演出を入れ、着火時には火との距離や風よけが成功条件に関係します。

---

## 2. 実装した機能一覧

- [x] 一人称視点の3Dシーンと、机のライター・手・煙草の表示
- [x] `Space` キーでライターを拾い、クリックや手の操作で上部スイッチに合わせて `B` キーで点火
- [x] `B` キーを押すたび、画面上部にスイッチまでの距離を表示
- [x] 点火時に炎が大きくなってから、煙草への着火画面へ遷移
- [x] ライターの位置、風よけ、炎の安定度を使った煙草への着火判定
- [x] 炎が煙草に届いている間の赤い火種と煙の演出
- [x] `E` キー長押しで吸い込み、火を定着させてクリア
- [x] 制限時間、失敗・クリア表示、リプレイ、ベストタイム保存
- [x] 時間経過に応じて手元や煙草が震える演出

## 3. 開発環境・起動手順

### 使用技術スタック

* **使用言語**：JavaScript / HTML / CSS
* **フレームワーク・ライブラリ**：Three.js、Vite
* **実行環境**：Node.js 20.19 以降、WebGL 対応ブラウザー

### アプリの起動方法

1. **事前準備・インストール**

   プロジェクトのルートディレクトリで依存パッケージをインストールします。

   ```bash
   npm ci
   ```

2. **開発サーバーの起動**

   ```bash
   npm run dev
   ```

   ターミナルに表示されたローカル URL をブラウザーで開いてください。

3. **本番用ビルドとプレビュー（必要な場合）**

   ```bash
   npm run build
   npm run preview
   ```

### 4-2. 思い通りのコードを引き出すための「プロンプトの工夫」

> **【実際にAIに送ったプロンプト（抜粋）】**  
> 「ライターに火をつけるのが簡単すぎるので右手を使用してライターの上部にあるスイッチを押して火をつけるようにしてください。」  
> 「火が付いたときに一瞬で画面が切り替わるのではなくライターの火の部分が大きくなってから切り替わるようにして下さい」

* **工夫したポイント・なぜこの指示が有効だったか**：  
  「点火する」だけでなく、使う手、押す場所、画面遷移のタイミングまで具体的に指定しました。操作や演出を一つずつ追加し、期待と異なる場合は距離や画面遷移など問題点を絞って伝えることで、変更内容を確認しやすくしました。

### 4-3. エラー・バグ解決の記録（デバッグの足跡）

* **発生したトラブル・エラー内容**：  
  画面上の距離が `0.19` と表示されているのに、Bキーを押してもライターに火がつきませんでした。
* **AIへの聞き方と解決プロセス**：  
  「0.19でもライター自体が着火しません」と現象を伝え、点火判定を確認しました。距離のしきい値以外に、ライターをクリックして右手を合わせたことを示す内部条件も必要になっていたため、その条件を取り除き、右手とスイッチの実際の距離で点火できるように修正しました。修正後はブラウザー上で点火を確認しました。

## 5. 開発を通じた振り返り・学び

AIを使うと、3D表示や操作の変更を素早く試せました。一方で、意図した操作になっているかは実際にゲームを動かして確かめる必要がありました。特に、距離表示が出ていても別の条件が点火を止めている不具合があり、画面表示だけでなく判定の流れを確認することが大切だと分かりました。機能を小さく追加し、その都度ブラウザーで試しながら進める方法が役立ちました。
