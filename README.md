# WINDPROOF — 火を守れ

Three.js と Vite で作られた、一人称視点のブラウザー向け 3D ミニゲームです。机のライターを拾って点火し、風から火を守りながら煙草の先端へ火を移すことを目指します。

## 必要環境

- Node.js 20.19 以降
- WebGL に対応した最新のブラウザー

## セットアップと起動

```bash
npm ci
npm run dev
```

ターミナルに表示されたローカル URL をブラウザーで開いてください。

## 遊び方

### 1. ライターを拾って点火する

1. スタート画面で「ゲームスタート」を選び、`Space` キーで机のライターを拾います。
2. ライターをクリックすると右手が上部のスイッチへ向かいます。必要に応じて矢印キーやマウスで手を調整します。
3. `B` キーでスイッチを押します。画面上部にスイッチまでの距離が表示され、手が届く範囲にあると点火します。
4. 点火すると炎が大きくなり、その後に煙草へ着火する画面へ切り替わります。

### 2. 煙草に火を移す

煙草の画面で「煙草に火を移す」を選び、以下の操作で炎を煙草の先端へ運びます。炎が先端に届いた状態で風を手で防ぎながら `E` キーを長押しすると、火が定着してクリアです。火が消えるか制限時間を過ぎると失敗になります。

| 操作 | 動作 |
| --- | --- |
| `W` `A` `S` `D` | ライターを上下左右に動かす |
| 矢印キー | 風よけの手を動かす |
| マウス移動 | 選択中の手を動かす |
| `Shift` | マウスで動かす手を切り替える |
| マウスホイール | 奥行きを調整する |
| `E` 長押し | 煙草を吸って火を定着させる |
| `R` | スタート画面へ戻る |

## ビルドとプレビュー

```bash
npm run build
npm run preview
```

## プロジェクト構成

- `index.html` — ゲーム開始画面とステージ画面
- `src/main.js` — Three.js のシーン、ゲーム状態、操作処理
- `src/style.css` — 画面レイアウトとスタイル
