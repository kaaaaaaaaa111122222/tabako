# WINDPROOF

Three.js 製のブラウザー向け一人称 3D ミニゲームです。ライターやマッチを指先で操って火をつけ、左手で風やお邪魔から炎を守りながら、口元の煙草に火をつけるまでのタイムを競います。操作感は Hand Simulator のような「体の部位をそのまま動かす」不器用さをイメージしています。

PC（マウスとキーボード）でも、スマホ（横向き・タッチ）でも遊べます。

## 起動方法

Node.js 20.19 以降が必要です。

```bash
npm install
npm run dev
```

表示されたローカル URL をブラウザーで開いてください。

### スマホで遊ぶ

- 同じ Wi-Fi のスマホで試す：`npm run dev -- --host` で起動し、表示された `Network` の URL をスマホで開く
- Web に置く：`npm run build` でできる `dist/` を、そのまま静的サイトとして公開する。相対パスで書き出すので、サブフォルダーに置いても動く
- PC でタッチ操作を確かめる：URL に `?touch` を付ける

## 難易度と場所

| 難易度 | 道具 | 場所 | 特徴 |
| --- | --- | --- | --- |
| かんたん | ライター | ベランダ | ホイールを何度も素早く擦って熱を溜め、満タンになったらそのままガスレバーを押し込んで点火 |
| ふつう | 箱マッチ | コンビニ前 | 箱のヤスリで擦って点火。燃え尽きる前に吸いつける。マッチは 10 本 |
| むずかしい | 紙マッチ | ビルの屋上 | 強く押すと折れる・すぐ燃え尽きる・風に弱い。マッチは 6 本 |
| おまけ | まったり喫煙 | 自分で選ぶ | 3 つの難易度を 60 秒以内にクリアすると解放。時間もお邪魔もなく、ただ吸って吐く |

まったり喫煙で選べる場所：ベランダ / コンビニ前 / ビルの屋上 / 純喫茶 / キャンプ場 / 港の防波堤 / 温泉宿の縁側

時間制限はありません。タイムでランク（S〜D）が決まり、**60 秒を超えると F** です。マッチを使い切ると失敗（F）になります。

## 遊び方

1. **拾う**：目の前の道具をクリック（タップ）で手に取る
2. **火をつける**：手元にズームした点火画面に切り替わる。握りが弱いとずり落ちて落とす
   - ライター：親指でホイールを何度も擦る。熱が満タンになったら、擦った勢いのままレバーへ
   - マッチ：頭をヤスリに押し付けて擦る。速く・強く・何度も擦るほど軸が傷んで折れる。紙マッチは押しすぎるとすぐ折れる
3. **吸いつける**：一人称視点に戻る。炎を煙草の先端に当てて吸う。吸いすぎるとむせる。火が消えたら点火画面からやり直し

### まったり喫煙

左手の人差し指と中指で煙草を挟み、吸うときだけ口元へ運びます。離すと手で下ろして、煙を吐きます。灰が長くなると自分で灰皿へ落とし（手動でも落とせます）、吸い終えたらもみ消して吸い殻を灰皿に残し、次の 1 本に火をつけます。

## 操作

### PC

**点火画面（手元）**

| 入力 | 動き |
| --- | --- |
| マウス移動 | 親指の先（マッチは頭）を動かす |
| クリック長押し | 押し付ける |
| `A` `S` `D` `F` | 小指・薬指・中指・人差し指で握る |

**吸いつけ（一人称）**

| 入力 | 動き |
| --- | --- |
| マウス移動 | 右手（炎）を動かす |
| クリック長押し | ライターのガスレバーを押さえ続ける（離すと消える） |
| `W` `A` `S` `D` | 左手（風よけ）を動かす |
| `Q` / `E` | 左手首を回して、手のひらの向きを決める（炎の方を向いていないと風を防げない） |
| `Shift` 長押し | 左手をすぼめて炎を覆う（近づけすぎるとやけど） |
| `F` 長押し | 左手を水平にして煙草の上にかざす（雨よけ） |
| `Space` 長押し / 右クリック長押し | 煙草を吸う |
| `Esc` | 一時停止（止まっている間は `Q` でタイトルへ、クリック / `Enter` で再開） |
| `R` | タイトルへ戻る（プレイ中は長押し） |

**まったり喫煙**

| 入力 | 動き |
| --- | --- |
| `Space` / クリック長押し | 口元へ運んで吸う。離すと下ろして吐く |
| `F` | 灰皿に灰を落とす |

### スマホ

| 場面 | 操作 |
| --- | --- |
| 点火画面 | 左の「握る」を押さえたまま、右側をなぞる。ライターは指を置き直すと、親指がホイールの後ろへ戻る |
| 吸いつけ | 右側をなぞって炎を動かす（ライターは触れている間だけガスが出る）。左のスティックで左手、「すぼめる」「かざす」は押すたびに切り替え、「吸う」は長押し。手のひらは自動で炎を向く |
| まったり喫煙 | 画面を長押しで吸う。「灰を落とす」で灰皿へ |

## お邪魔イベント

- **突風**：予告された風上側へ左手を回し、手のひらを炎へ向けてすぼめる
- **蛾**：炎に寄ってくるので左手で払いのける
- **急な雨**：左手を水平にして、煙草の先の上にかざす
- **一本くれよおじさん**：横から手を出してくる。おじさん側で左手を左右に振って追い返す
- **ライター貸してくださいおじさん**：右手の道具へ手を伸ばしてくるので、右手を遠ざけて断る
- **くしゃみ**：連打してこらえる（点火画面でも起きる）
- **スマホ通知**：通知を左右にスワイプして全部消す（点火画面でも起きる）
- **着信**：スマホの「拒否」を押す（点火画面でも起きる）

## 素材の作り方

モデル・背景・質感・効果音は、ローカルの ComfyUI で作っています。プロンプトとシード、採用した番号は `tools/assetgen/` に残してあるので、同じ手順で作り直せます。

| 素材 | 使うもの | スクリプト |
| --- | --- | --- |
| 写真・背景 | FLUX.2 klein 4B | `gen.py photos` / `gen.py images`（中身は `specs.py`） |
| 3D モデル | TRELLIS.2（写真 → GLB） | `gen.py mesh --only 名前` |
| 手のリギング | Blender 4.5 | `bl_hand.py`（ゲームの手の寸法へ変形して骨を入れる） |
| 人物のリギング | Blender 4.5 | `bl_people.py`（頭・両腕・口の動き） |
| 小物の整形 | Blender 4.5 | `bl_props.py`（当たり判定と同じ寸法へ合わせる） |
| 画像の仕上げ | Pillow | `prep_images.py` |
| 効果音・環境音 | Stable Audio 3 small SFX | `sfx.py gen` → `sfx.py build` |

ComfyUI（`127.0.0.1:8188`）を起動してから、ComfyUI の Python で実行します。途中の写真や GLB は `ComfyUI/output/tabako/` に残ります。

```bash
cd tools/assetgen
C:/Users/jyori/ComfyUI/.venv/Scripts/python.exe gen.py photos --only lighter_body
C:/Users/jyori/ComfyUI/.venv/Scripts/python.exe gen.py mesh --only lighter_body --faces 8000 --tex 1024
"C:/Program Files/Blender Foundation/Blender 4.5/blender.exe" -b -P bl_props.py -- C:/Users/jyori/ComfyUI/output/tabako/glb ../../src/assets/models lighter
```
